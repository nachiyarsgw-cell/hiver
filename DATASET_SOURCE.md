# Dataset Source

This project uses the public **Customer Support on Twitter (TWCS)** dataset by Thought Vector (Kaggle). The raw dataset is not bundled because it is large. A 50,000-pair AmazonHelp subset was prepared from the provided TWCS archive.

Brand: **AmazonHelp**

The experiment data in `data/amazon_pairs.csv` is the prepared customer → AmazonHelp response subset.
